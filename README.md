# FinancePulse Premium Dashboard 📈

A high-performance, desktop-class financial management dashboard designed for precision and clarity.

![Dashboard Preview](https://images.unsplash.com/photo-1551288049-bebda4e38f71?auto=format&fit=crop&q=80&w=1000)

## ✨ Features
- **Real-time Overview**: Track balance, income, and expenses at a glance.
- **Smart Goals**: Progress-tracked savings goals with visual motivation.
- **Transaction History**: Detailed, categorized logs with premium animations.
- **Micro-animations**: Powered by Framer Motion for a fluid experience.
- **Glassmorphism**: Ultra-modern UI with soft blurs and depth.

## 🚀 Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## 🛠️ Installation
```bash
npm install
npm run dev
```
